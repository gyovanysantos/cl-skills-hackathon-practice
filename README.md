# cl-skills-hackathon-practice

Practice repo for the CentriLogic Claude Skills Hackathon (2026-09-11). Builds **Skill 2 —
Financial Summary from CIM** end to end against **fabricated mock data**, to rehearse:
GitHub issues from a skill, the implement→PR→CI loop, versioned release packaging, and
installing a plugin marketplace into **Claude Cowork**.

Not real client work. See `docs/` for the requirements/design (SDLC stages 1–3) and
`plugins/cl-cim-financial-summary/` for the plugin itself.
